Questions

How do I audit Linux server hardening?

Open the relevant configuration (for example sshd_config or sysctl settings) in ConfGoOne. It checks it against hardening rules and shows each issue with the fix.

Can it audit Windows Group Policy?

Yes. Windows security settings and Group Policy exports are checked for issues such as SMBv1, NTLM level, password and lockout policy and RDP settings.

Which web servers and databases are supported?

Apache, Nginx and IIS; MySQL, PostgreSQL and Microsoft SQL Server.

Does it install an agent on my servers?

No. ConfGoOne works from configuration files or a live connection you start — nothing is installed on the server.
